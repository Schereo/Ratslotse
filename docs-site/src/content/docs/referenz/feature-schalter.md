Diese Seite entsteht aus `kern/features.py` (`python scripts/docs_reference.py`). Wer sie von Hand ändert, verliert die Änderung beim nächsten Lauf; `tests/test_docs_current.py` hält sie gegen das Register.

Ein Schalter trennt Ausliefern von Freischalten: Der Code fährt fertig nach `main` und bleibt dunkel, bis `FEATURE_FLAGS` in der `.env` des Servers ihn nennt. **Auf dev sind alle Schalter an** (`FEATURE_FLAGS=*`); welche auf Prod an sind, steht nur dort. Die Oberflächen lesen die Liste über `GET /api/app-config`. Ein Schalter ist keine Rechteprüfung (dafür gibt es [Rollen und Rechte](/docs/referenz/rollen-rechte/)) und er ist eine Schuld: Die Spalte „Fertig, wenn“ nennt, woran man erkennt, dass er wieder wegkann.
