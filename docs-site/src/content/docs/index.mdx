Die Dokumentation richtet sich an Entwickler*innen und Betreiber*innen.
Sie beschreibt den Aufbau des Systems und begründet technische
Entscheidungen. Hilfe zur Nutzung steht auf [ratslotse.de](https://ratslotse.de).
