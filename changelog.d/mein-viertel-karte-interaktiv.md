**Die Karte von „Mein Viertel“ reagiert jetzt auf den Zeiger.** Wer auf einen Pin, eine Straßenlinie oder eine Planfläche zeigt, sieht das Vorhaben wachsen und einen Hinweis mit Stand, Termin und Name; zeigt man auf eine Zeile der Liste, hebt sich ihr Pin auf der Karte, und umgekehrt hebt ein Pin seine Zeile. Ein Tipp auf einen Pin wählt das Vorhaben direkt — bisher brauchte es erst ein Popup und darin einen zweiten Tipp. Das gewählte Vorhaben trägt ein Namensschild und einen pulsierenden Ring, damit man auf der Karte findet, was man angeklickt hat.
